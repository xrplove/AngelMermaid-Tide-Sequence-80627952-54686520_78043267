# Angel Mermaid Tide

## Project purpose
This repository is a cinematic, spiritual, multi-dimensional concept project centered on Ursula's redemption, memory, release, and awakening.

The project is not just a static page or a simple visual showcase. It is a storyworld and experiential concept that blends:
- dreamlike spiritual narrative
- cosmic / celestial atmosphere
- multi-dimensional themes
- VR / animated film concept design
- visual mood and identity exploration

## Core identity
- Title: Angel Mermaid Tide
- Theme: redemption, release, awakening, memory, love, conscience
- Medium: VR experience / animated film concept
- Tone: luminous, dreamlike, spiritual, cinematic, mythic

## What this project is
The project imagines Ursula moving through layered realities shaped by conscience, deep sleep, and the tide of release. The angel-mermaid becomes a vessel for forgiveness, surrender, and transformation.

This repo should be treated as a concept / worldbuilding / creative experience project rather than a conventional full-stack application.

## Key files
- `index.html` – primary landing page / story presentation
- `styles.css` – visual design and atmosphere
- `app.js` – interactive behavior and page logic
- `README.md` – repo overview and project documentation

## How to run locally
Because this is a static site, there is no build step required.

Open `index.html` directly in a browser, or serve the folder with a simple local HTTP server.

Examples:
- `python -m http.server 8000`
- then open `http://localhost:8000`

## Design expectations
When making changes, preserve the following:
- ethereal / cosmic atmosphere
- deep blue, black, cyan, and obsidian palette
- mythic / spiritual symbolism
- dreamy but intentional pacing
- storytelling-first composition
- no overuse of generic corporate web language

## Editing guidance
- Prefer preserving the artistic tone and concept language.
- Do not replace the project’s mystical atmosphere with generic business-site phrasing.
- If adding new content, keep it in the same cinematic / spiritual register.
- Any documentation updates should reinforce the concept, not flatten it.

## Success criteria
A good change should:
- preserve the dreamlike spiritual atmosphere
- keep the project readable and elegant
- maintain the cosmic / celestial visual identity
- respect the narrative tone of the concept
- avoid turning the project into a generic landing page

## If you are unsure what to do
Default to preserving the original mood and concept intention. This is a creative worldbuilding project, not a standard utility repo.

Focus on:
- atmosphere

- story-driven presentation
